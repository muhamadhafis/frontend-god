# Glossary & Terminologi Teknis

- **OKLCH**: Ruang warna perseptual seragam (Lightness, Chroma, Hue) yang menjadi standar warna semantik Tailwind CSS v4 & shadcn.
- **Cockpit Mode**: Arsitektur antarmuka berkepadatan data tinggi (data-dense), spasi rapat (`p-3`), tinggi baris $\le 36$px, dan minim dekorasi.
- **Marketing Mode**: Arsitektur antarmuka lapang (airy) dengan padding makro (`py-24+`), display typography besar, dan fokus storytelling visual.
- **Self-Healing Delivery Gate**: Mekanisme audit mandiri sebelum turn selesai, mencakup verifikasi build/typecheck dan formatting.
- **RSC (React Server Components)**: Komponen React yang dieksekusi di sisi server secara default, meminimalkan JavaScript bundle pada klien.
